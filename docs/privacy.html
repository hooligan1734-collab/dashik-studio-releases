Политика конфиденциальности Dashik Studio

Дата последнего обновления: 17 сентября 2026 г.

Dashik Studio — desktop-приложение для создания коротких видео, работающее локально на компьютере пользователя. Эта страница описывает, как приложение обрабатывает данные, полученные через Google API (YouTube Data API и YouTube Analytics API), когда пользователь по своей инициативе подключает собственный YouTube-канал.

Какие данные запрашиваются

После явного согласия пользователя на экране входа Google приложение получает доступ к:

  • базовой информации о канале пользователя (название, ID, список загруженных видео);
  • возможности загружать видео и обложки на канал пользователя от его имени;
  • статистике по видео пользователя (просмотры, удержание, источники трафика) через YouTube Analytics API.

Приложение не запрашивает и не получает доступ к данным других пользователей YouTube, только к каналу, который сам пользователь подключил в настройках приложения.

Как данные используются

Все полученные данные используются исключительно внутри приложения, на устройстве пользователя, для отображения статистики канала и публикации видео, которые пользователь сам создал в приложении. Приложение не анализирует, не продаёт и не передаёт эти данные каким-либо третьим лицам, рекламным сетям или аналитическим сервисам.

Где хранятся данные

Токен доступа (OAuth refresh token) хранится локально на компьютере пользователя, в папке профиля приложения (userData/youtube-tokens.json). Он не передаётся и не синхронизируется ни на какой сервер разработчика — у Dashik Studio нет собственного backend-сервера, приложение обращается к API Google напрямую с устройства пользователя.

Отзыв доступа

Пользователь может в любой момент отключить доступ приложения к своему аккаунту:

  • кнопкой «Отключить аккаунт» в настройках Dashik Studio — удаляет локально сохранённый токен;
  • либо через страницу Google Account → Security → Third-party apps with account access — отзывает доступ на стороне Google.

Соответствие политике Google

Использование и передача информации, полученной через API Google, приложением Dashik Studio соответствует Google API Services User Data Policy, включая требования Limited Use.
